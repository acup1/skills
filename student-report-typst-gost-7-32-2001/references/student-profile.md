# Местные профили оформления

Это университетские настройки, а не перечень требований ГОСТ 7.32-2001. Настройки пользователя/преподавателя имеют приоритет.

| Параметр | student-lab | student-course |
| --- | --- | --- |
| Бумага | A4 | A4 |
| Основной текст | Times New Roman 14 пт, чёрный | То же |
| Абзац | По ширине, первая строка 1,25 см, интервал 1,5; до/после 0 пт без сжатия шага строк на границе абзацев | То же |
| Переносы слов | Автоматические переносы выключены во всём документе | То же |
| Поля слева/справа/сверху/снизу | 30/10/20/20 мм | 30/15/20/20 мм |
| Заголовки | Полужирные; уровни 1–3 слева, структурные по центру прописными | Полужирные; главы прописными по центру, подразделы слева |
| Номера заголовков | С точкой в конце: `1.`, `2.3.`, `3.1.2.` | То же |
| Разрывы перед обычными разделами | Нет; пункты всех уровней идут подряд | Новый раздел уровня 1 — новая страница; уровни 2–3 продолжаются |
| Структурные разделы | Введение, вывод/заключение, содержание и т. п. с новой страницы; следующий раздел также отдельно | То же |
| Рисунки и таблицы | Сквозная нумерация | Сквозная нумерация |
| Формулы | `(1)`, `(2)` | `(1.1)`, `(1.2)`, `(2.1)` по главам |
| Ссылки в тексте | `рис. N`, `табл. N` | То же |
| Содержание | Выключено | Включено, глубина 2 |

Заголовки: TNR 14 пт, без абзацного отступа, с интервалами до/после 12/6, 9/6 и 6/3 пт для уровней 1–3. Сохраняй семантику heading/Heading и удержание с последующим текстом. Полная таблица типов — в разделе «Заголовки всех уровней» файла [SKILL.md](../SKILL.md).

Общее: один рисунок на строку, подпись рисунка снизу по центру, таблицы сверху слева; полные подписи `Рисунок N – ...` / `Таблица N – ...`, чёрные границы и отсутствие заливки. Упоминание объекта в тексте перед ним обязательно. Номер страницы снизу по центру, титул считается первой страницей, его номер скрыт. Имена — `Фамилия И. О.`. Математика использует отдельный явно заданный математический шрифт.

Титул выбирается отдельно; `student-course` не навязывает титул МАИ. От пользовательской курсовой сохранены компоновка титула, вариант, должность проверяющего, содержание, уровни заголовков, списки и идея нумерации формул по главам. Исправлены ошибки образца: таблицы имеют собственные ссылки и подписи сверху, номера формул заключены в круглые скобки, счётчик сбрасывается только на уровне главы. По явному пользовательскому правилу после номера каждого заголовка ставится точка. Тему БЧХ, имена, образцовые значения таблиц и `lorem` в новые отчёты не переносить.

В `gost-2001-strict` короткие ссылки и полужирные заголовки отключены. TNR 14 и 1,25 см допустимы как выбранные настройки, но не объявляются нормативными требованиями. Точка после номера заголовка — явное пользовательское исключение из нормативной справки. Университетский титул, отсутствие некоторых структурных элементов и оформление переноса таблиц требуют отдельного рассмотрения, прежде чем заявлять полное соответствие стандарту.
